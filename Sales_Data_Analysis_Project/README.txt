# Sales Data Analysis Project

## Objective
Analyze sample sales data and create five visualizations using Python, Pandas, and Matplotlib.

## Files
- `data/sales_data.csv` — sample dataset (264 orders from 2025)
- `sales_analysis.py` — complete analysis and chart-generation code
- `charts/` — five generated chart images
- `requirements.txt` — required Python packages

## How to run (Windows)
1. Install Python 3.10 or newer.
2. Extract this ZIP file.
3. Open the extracted `Sales_Data_Analysis_Project` folder in VS Code.
4. Open Terminal > New Terminal.
5. Run: `py -m pip install -r requirements.txt`
6. Run: `py sales_analysis.py`
7. The summary will appear in the terminal and the five PNG charts will be saved in `charts`.

If `py` does not work, try replacing `py` with `python`.

## Five visualizations
1. Monthly sales (bar chart)
2. Sales share by category (pie chart)
3. Top 10 products by sales (horizontal bar chart)
4. Sales vs profit (scatter plot)
5. Region-wise sales (bar chart)

## Important note
This is a generated practice dataset for a beginner project, not real company sales records. If your instructor gave you a dataset, use that instead and update the file path/column names as needed.
